# Подсветка HTML

Neovim `0.12.5` ограничивает запрос Tree-sitter 256 одновременно
обрабатываемыми совпадениями. В HTML с глубокой вложенностью этот предел
обрывает захваты `@tag` и `@tag.delimiter` в середине документа: имена тегов
теряют цвет, хотя дерево разбора остаётся корректным. Это воспроизводилось на
сбалансированном документе с 40 уровнями вложенности.

`functions.treesitter.configure_html_highlights()` повышает предел до 512
только для запроса `html/highlights`. Явно переданный вызывающим кодом
`match_limit` сохраняется. Обход действует для обычного HTML и HTML,
встроенного в `htmldjango`; другие языки и содержимое буфера он не меняет.
Новые зависимости не требуются.

Проверка из корня конфигурации:

```sh
rtk env XDG_CACHE_HOME=/private/tmp/nvim-html-cache XDG_STATE_HOME=/private/tmp/nvim-html-state nvim --headless -u NONE -i NONE -n -l tests/html_highlight_limit_spec.lua
```

Тест создаёт вложенный документ в памяти, проверяет захваты на открывающих
и закрывающих тегах после движения курсора, а также встроенный HTML в
`htmldjango`. Для запуска нужны установленные парсеры и запросы `html` и
`htmldjango`. Предел 512 не гарантирует подсветку при произвольно большой
глубине; после обновления Neovim или `nvim-treesitter` нужно перепроверить
тест и необходимость обхода.
