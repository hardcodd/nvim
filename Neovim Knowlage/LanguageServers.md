# Языковые серверы и проверка разметки

Mason устанавливает инструменты в `stdpath("data") .. "/mason"`.
`mason-lspconfig.nvim` устанавливает и включает серверы из списка
`lua/config/lsp.lua`. Другие установленные в Mason серверы автоматически
не включаются. `nvim-lspconfig` предоставляет стандартные настройки для
встроенного клиента Neovim; отдельные переопределения находятся в
`after/lsp/<server>.lua`.

## Подключённые инструменты

| Файлы | Инструменты | Назначение |
| --- | --- | --- |
| HTML | `html`, HTMLHint | Подсказки тегов и атрибутов; проверка разметки. |
| Django (`htmldjango`) | `html`, djLint с профилем `django` | HTML-подсказки и проверка шаблонной разметки. HTMLHint здесь не запускается. |
| JavaScript, TypeScript, React (`.jsx`, `.tsx`) | `vtsls`, `eslint` | Синтаксис, типы и проектные правила ESLint. |
| Vue (`.vue`) | `vue_ls`, `vtsls`, `eslint` | Шаблон, стили и код внутри компонента; проектные правила ESLint. |
| HTML, Django, JSX/TSX, Vue, CSS/SCSS/Sass/Less | `emmet_language_server` | Сокращения Emmet и поля сниппетов. |

Для Vue `vtsls` загружает `@vue/typescript-plugin` из установки
`vue-language-server` в Mason. `ts_ls` одновременно не включён. Базовая
настройка рассчитана на Vue 3; Vue 2 требует другой версии сервера и
дополнительных проектных настроек.

ESLint подключается при наличии проектной конфигурации и использует пакет
`eslint` и плагины из проекта. Установка сервера не создаёт правила React/Vue
и не устанавливает зависимости в проект. Диагностика типов зависит от
`tsconfig.json`/`jsconfig.json` и доступных типов зависимостей; проверка типов
JavaScript требует `checkJs` или `// @ts-check`.

`vtsls` подключается только к буферу с именем файла. Это исключает
воспроизводимое падение TypeScript 5.9.3 на быстрых изменениях безымянных
буферов с разметкой. Обычные файлы используют стандартное определение корня
проекта и передачу только изменений; после назначения имени безымянному
буферу переоткройте его, если клиент ещё не подключился.

Neovim распознаёт распространённые Django-теги в первых 40 строках HTML.
Если шаблон остался `html`, используйте `:set filetype=htmldjango`.
djLint проверяет разметку и часть правил шаблонов; он не выполняет Django,
не проверяет существование view/context-переменных и не заменяет тесты проекта.
HTML LSP не даёт полного анализа Django-синтаксиса; его форматирование
выключено, чтобы не менять шаблонные конструкции.

## Установка и обслуживание

Нужны доступные из Neovim Node.js с npm, Python 3 с `venv` и `pip`, сетевой
доступ к GitHub, npm и PyPI. Плагины и недостающие инструменты устанавливаются
при запуске. Дождитесь завершения в `:Mason`, затем перезапустите Neovim,
чтобы TypeScript загрузил Vue-плагин. В headless-режиме `mason-lspconfig`
не устанавливает серверы автоматически.

- `:Mason` — состояние инструментов, установка и обновление.
- `:LspInstall html vtsls vue_ls eslint emmet_language_server` — установка начального списка LSP.
- `:MasonToolsInstall` — установка недостающих HTMLHint и djLint.
- `:MasonLog` — ошибки установки; `:checkhealth mason` — зависимости.
- `:checkhealth vim.lsp` — включённые серверы и подключённые клиенты.
- `:set filetype?` — фактический тип текущего буфера.

Автоматические обновления линтеров выключены. `lazy-lock.json` фиксирует
версии плагинов, но не версии программ Mason. Удаление имени из списка
не удаляет установленную программу; обновление и удаление выполняются
отдельно через Mason.

## Добавление языка

1. Добавьте имя конфигурации `nvim-lspconfig` в `servers` в
   `lua/config/lsp.lua`, например `"lua_ls"`.
2. При необходимости создайте `after/lsp/lua_ls.lua`, возвращающий таблицу
   переопределений `vim.lsp.Config`. Стандартный конфиг целиком копировать
   не требуется.
3. Перезапустите Neovim, дождитесь установки в Mason и откройте файл языка.
   Проверьте клиента через `:checkhealth vim.lsp`.

Пример отдельного переопределения:

```lua
return {
  settings = {
    Lua = { diagnostics = { globals = { "vim" } } },
  },
}
```

Линтеры настраиваются в `lua/config/lint.lua`: `tools` содержит имена пакетов
Mason, `linters_by_ft` — имена линтеров `nvim-lint`. Обработчики находятся
в `functions.lsp` и `functions.lint`; нестандартный обработчик размещается
в `lua/functions/`, а файл сервера ссылается на него.

## Использование и проверка

Диагностика подчёркивает текст и показывается рядом со строкой. `[d` / `]d`
переходят по сообщениям, `Space d` открывает сообщение у курсора. LSP
проверяет изменения; HTMLHint/djLint запускаются при входе в буфер, после
сохранения и выхода из Insert mode. Они читают содержимое буфера без
перезаписи файла; проектные правила ищутся от каталога файла. Пока инструмент
не установлен, его запуск пропускается; ошибки установки видны в Mason.

Меню дополнения открывается на триггерах сервера; `Ctrl+x Ctrl+o` вызывает
его вручную, `Ctrl+n` / `Ctrl+p` выбирают вариант, `Ctrl+y` принимает.
`Tab` принимает выбранный вариант; `Enter` сохраняет обычное поведение и
парные теги. `gd` переходит к определению;
стандартные клавиши Neovim `K`, `grr`, `grn`, `gra` дают справку, ссылки,
переименование и действия. Автоформатирование и исправление при сохранении
не включены.

## Emmet

`emmet_language_server` использует `@vscode/emmet-helper`, как интеграция
Emmet в VS Code. Он устанавливается через тот же Mason; отдельный плагин
сниппетов не нужен. Настройки языков и Emmet находятся в
`after/lsp/emmet_language_server.lua`, обработчики — в `functions.emmet`.

В Insert mode введите `ul>li.item$*3` и нажмите `Tab`: появятся список и
три элемента с классами `item1`–`item3`. `!` создаёт каркас HTML-документа;
`.card` в JSX/TSX использует `className`. В CSS и блоке `<style>` Vue
`m10` превращается в `margin: 10px;`. Вложенность учитывает действующие
`shiftwidth` и `expandtab`, включая проектные настройки.

Порядок действий `Tab`: принять выбранную подсказку; перейти к следующему
полю активного сниппета; запросить разворачивание Emmet; вставить обычный
отступ, если сокращения нет. `Shift+Tab` возвращает к предыдущему полю;
без такого поля действует стандартная клавиша. Переходы работают также
в Select mode. Меню не выбирает первый вариант автоматически, поэтому
`Ctrl+n` / `Ctrl+p` позволяют явно выбрать подсказку.

Это интеграция сокращений и дополнения, а не весь набор команд Emmet
из VS Code: оборачивание выделения, балансировка и другие команды отдельно
не подключены. Контекст подсказок определяет сервер; в смешанных языках
он может предложить HTML вне разметки. Не выбирайте такую подсказку в коде.
Обычные `.js`/`.ts` не включены в список языков Emmet.

Проверки конфигурации и реальных серверов описаны в [[Operations]]. Для
ручной проверки откройте ошибочные HTML, Django, JSX/TSX и Vue-файлы, затем
исправьте ошибки: сообщения должны исчезнуть без изменения содержимого
другими инструментами. React/Vue проверяйте с зависимостями проекта.
