# Комментарии

## Установленные плагины

- `numToStr/Comment.nvim` добавляет построчное и блочное комментирование.
- `JoosepAlviste/nvim-ts-context-commentstring` выбирает синтаксис комментария
  по положению курсора через Tree-sitter. Интеграция вызывается непосредственно
  перед действием `Comment.nvim`; ожидать `CursorHold` не нужно.
- `folke/todo-comments.nvim` подсвечивает `TODO:` и `FIXME:` в комментариях и
  открывает поиск по проекту через Telescope. Используется уже установленный
  `plenary.nvim`. Все три плагина закреплены в `lazy-lock.json`.

## Управление

| Клавиши | Действие |
| --- | --- |
| `gcc` | Переключить построчный комментарий на текущей строке. |
| `gc` + движение, выделение и `gc` | Переключить построчные комментарии в диапазоне. |
| `gbc` | Переключить блочный комментарий на текущей строке. |
| `gb` + движение, выделение и `gb` | Переключить блочный комментарий в диапазоне. |
| `gco`, `gcO`, `gcA` | Добавить строку комментария ниже, выше или в конце строки. |
| `Space f t` | Открыть поиск `TODO:` и `FIXME:` через `:TodoTelescope`. |

`Comment.nvim` задаёт клавиши `gc` и `gb` вместо штатных клавиш Neovim.
`Space f t` задаётся в `lua/keymaps.lua`. Поиск также доступен командой
`:TodoTelescope`; ему нужны `rg`, Telescope и `plenary.nvim`. Если `rg` нет,
комментирование и подсветка открытого файла продолжают работать.

В JSX/TSX используются комментарии вида `{/* ... */}`. В Vue обычное
содержимое `<script>` комментируется через `//`, содержимое `<style>` — через
`/* ... */`, а сами теги — через `<!-- ... -->`. Если Tree-sitter распознаёт
вложенный язык, его правило имеет приоритет. В других вложенных языках
результат зависит от доступного парсера и правил Tree-sitter. Если контекст
определить нельзя, используется `commentstring` текущего буфера. Для `TODO:`
и `FIXME:` нужно двоеточие после слова;
подсветка ограничена настоящими комментариями при доступном Tree-sitter или
синтаксическом определении комментариев. Знаки в боковой колонке выключены,
а значки в результатах поиска используют обычные ASCII-символы.

В `htmldjango` плагин проверяет пометки после разбора вложенного HTML на
строке с ключевым словом: иначе при открытии файла `TODO:` внутри `<!-- -->`
может остаться без плашки. Текст вне комментариев по-прежнему не подсвечивается.

В Catppuccin Latte текст на плашках белый, в Mocha чёрный. Фоны сохраняют
исходные цвета палитры в обеих темах. На некоторых светлых фонах контраст с
белым текстом ниже `4.5:1`; это принято ради сохранения цвета плашек. Цвет
остального текста пометки сохраняет оттенок палитры. При переключении темы
цвета обновляются. Вид в конкретном терминале требует ручной проверки.

## Проверка

Из корня конфигурации запусти:

```sh
rtk nvim --headless -i NONE -n '+lua dofile("tests/comments_integration.lua")' +qa!
```

Тест проверяет `gcc`, `gc`, `gbc`, синтаксис JSX и Vue, подсветку `TODO:` и
`FIXME:` только в комментариях, в том числе в `htmldjango` до разбора
вложенного HTML, поиск и цвета плашек в обеих темах. Для ручной проверки открой
файл TSX, переключи комментарий внутри JSX, затем открой Django-шаблон с
`<!-- TODO: ... -->` и запусти `Space f t` в проекте с пометками `TODO:`.
